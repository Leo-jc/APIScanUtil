# HarmonyOS 变更分类分析报告

> 生成日期：2026-08-12
> 数据来源：`harmonyos_api_changes/`（24 个 JSON 文件）与 `harmonyos_behavior_changes/`（29 个 JSON 文件，已排除非数据文件 `wangzhi.txt`）
> 计数已逐文件校验：每个 JSON 内嵌的 `totalChanges` 字段均与实际记录数逐一吻合，无偏差。

## 总览

| 目录 | 文件数 | 变更总数 | 分类维度（字段） |
|---|---|---|---|
| `harmonyos_api_changes/` | 24 | **28,455** | `operation`（变更操作类型，42 类） |
| `harmonyos_behavior_changes/` | 29 | **163** | `interfaceChanges.changeType`（8 类）、`changeReasonCategory`（变更原因，7 类）、`apiEffectiveVersion`（生效隔离性，3 类） |

两类数据结构不同：
- **API 变更**：`kits[].changes[].operation` 描述对具体 API 声明的增删改。
- **行为变更**：`interfaceBehaviorChanges[].interfaceChanges` 描述运行时行为/UX 的变更，按 `changeType` 与 `changeReasonCategory` 双重分类。
